# Spoty 🎵

Простой mp3-плеер для Android, написанный на **Kotlin** с использованием **Jetpack Compose**.

## ✨ Возможности

- 🎧 Воспроизведение локальных mp3-файлов
- 📂 Сканирование всей музыки на устройстве или выбор конкретной папки вручную
- 🖼 Отображение обложек альбомов
- 📋 Создание и управление плейлистами
- 🔀 Перемешивание треков (shuffle)
- 🔁 Повтор: off / all / one
- 🔍 Поиск по названию, артисту или альбому
- 🌓 Тёмная и светлая темы
- 🔈 Регулировка системной громкости прямо в плеере
- 📱 Фоновое воспроизведение + плеер в шторке уведомлений
- 💥 Свайп-действия: удалить трек, добавить в плейлист, убрать из плейлиста
- 🎨 Кастомная иконка приложения

## 🛠 Технологии

- **Kotlin**
- **Jetpack Compose** — весь UI
- **Media3 (ExoPlayer)** — воспроизведение
- **Media3 Session** — фоновая работа + уведомление в шторке
- **MediaStore** — сканирование музыки
- **SharedPreferences** — хранение плейлистов и настроек
- **Material 3** — дизайн

## 📋 Требования

- Android 15+ (API 35)
- Устройство с музыкой в памяти
